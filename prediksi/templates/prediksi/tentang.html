Tentang aplikasi

PadiPredict

PadiPredict membantu melihat data produksi padi di Sumatera, membandingkan hasil antarwilayah, dan membuat perkiraan produksi berdasarkan luas panen serta kondisi iklim.

01

Data yang digunakan

Dataset mencatat produksi padi dari {{ jumlah_provinsi }} provinsi selama {{ tahun_awal|default:"-" }}–{{ tahun_akhir|default:"-" }}. Data yang tersedia meliputi:

  • Provinsi dan tahun pencatatan
  • Produksi dan luas panen
  • Curah hujan, kelembapan, dan suhu rata-rata
02

Django di dalam aplikasi

PadiPredict dibuat dengan Django. Django mengatur alamat setiap halaman, menerima input, dan menghubungkan tampilan dengan data.

  • URL dan view: mengarahkan permintaan ke fungsi yang sesuai.
  • Model dan ORM: membaca serta mengelola catatan padi di SQLite.
  • Form: memeriksa input sebelum dipakai untuk prediksi.
  • Template: menampilkan tabel, grafik, dan hasil ke halaman web.
  • Django Admin: membantu mengelola data melalui panel administrator.
  • Django
  • Python
  • SQLite
  • HTML dan CSS
03

Cara kerja prediksi

Pengguna memilih provinsi dan mengisi tahun, luas panen, curah hujan, kelembapan, serta suhu rata-rata. Data tersebut kemudian diproses oleh model untuk memperkirakan produksi.

Dua model yang tersedia untuk dibandingkan:

  • Linear Regression
  • Random Forest
04

Pelatihan dan evaluasi

Data tahun 1993–2015 dipakai untuk melatih model, sedangkan data tahun 2016 dan seterusnya dipakai untuk pengujian. Hasilnya dinilai dengan beberapa ukuran:

  • MAE dan RMSE: menunjukkan besar kesalahan prediksi; makin kecil biasanya makin baik.
  • R²: menunjukkan seberapa baik model menjelaskan variasi pada data uji.
05

Fitur yang tersedia

  • Data Dataset: melihat catatan produksi padi.
  • Analisis Data: membandingkan produksi per provinsi dan tahun.
  • Prediksi Produksi: mencoba perkiraan dengan dua model.
  • Evaluasi Model: melihat hasil pengujian model.
  • Asisten AI: bertanya tentang aplikasi dan data.
  • Administrator: mengelola data melalui Django Admin.
06

Catatan penggunaan

Hasil prediksi adalah perkiraan, bukan angka produksi yang pasti. Pastikan satuan input sesuai dengan data yang digunakan. Hasil sebaiknya menjadi bahan pertimbangan, bukan satu-satunya acuan.
